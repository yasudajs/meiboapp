# 名簿アプリ 開発前検討事項

## 🔧 技術仕様の詳細化

### 1. フロントエンド技術選択 ✅ **決定済み**
**確定した技術スタック：**
- **JavaScriptフレームワーク**: ✅ **Vue.js**
- **CSSフレームワーク**: ✅ **Bootstrap 5**
- **バンドラー**: Vite（推奨）
- **状態管理**: ローカル状態のみ（小規模のため）

**選択理由**: 開発効率、学習コスト、保守性のバランスが最適

### 2. バリデーション仕様の詳細化

#### 2.1 入力項目のバリデーション
**氏名**:
- 最大文字数: 50文字
- 禁止文字: 数字、記号（一部例外: ・ー）
- 必須チェック

**フリガナ**:
- 全角カタカナのみ許可
- 最大文字数: 100文字
- 「・」「ー」は許可

**メールアドレス**:
- RFC準拠の形式チェック
- 最大254文字
- 重複チェック（既存ユーザーとの重複禁止）

**生年月日**:
- 1900年1月1日〜現在日まで
- 形式: YYYY-MM-DD

**住所**:
- 郵便番号: 7桁数字（123-4567形式）
- 都道府県: プルダウン選択
- 市区町村: 最大100文字
- 番地等: 最大200文字

**電話番号**:
- 形式: ハイフンあり（090-1234-5678）またはなし
- 10〜11桁の数字のみ

### 4. API設計仕様

#### 4.1 認証関連
```
POST /api/auth/login
POST /api/auth/logout
POST /api/auth/refresh
POST /api/auth/change-password
```

#### 4.2 連絡先管理
```
GET    /api/contacts           # 一覧取得
POST   /api/contacts           # 新規登録
GET    /api/contacts/{id}      # 詳細取得
PUT    /api/contacts/{id}      # 更新
DELETE /api/contacts/{id}      # 削除
GET    /api/contacts/search    # 検索
```

#### 4.3 ユーザー管理（管理者のみ）
```
GET    /api/users              # ユーザー一覧
POST   /api/users              # ユーザー登録
PUT    /api/users/{id}         # ユーザー情報更新
PUT    /api/users/{id}/role    # 権限変更
```
