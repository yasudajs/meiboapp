# データベース仕様書（MeiboApp）

## 1. 概要
- 本仕様書は名簿管理システム（MeiboApp）のデータベース設計を明記するものです。
- RDBMS: SQLite（開発・本番共通）
- 文字コード: UTF-8

## 2. テーブル定義一覧

### 2.1 users（ユーザー）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| user_id              | INTEGER      | PRIMARY KEY AUTOINCREMENT | ユーザーID（主キー） |
| username             | TEXT(64)     | NOT NULL            | ユーザー名             |
| email                | TEXT(128)    | NOT NULL UNIQUE     | メールアドレス（ログインID） |
| password_hash        | TEXT(256)    | NOT NULL            | パスワードハッシュ      |
| user_role            | TEXT(16)     | NOT NULL            | ユーザー権限（admin/user） |
| is_active            | INTEGER      | NOT NULL DEFAULT 1  | アクティブフラグ（1:有効, 0:無効） |
| last_login           | DATETIME     |                     | 最終ログイン日時        |
| password_changed_at  | DATETIME     |                     | パスワード変更日時      |
| created_at           | DATETIME     | NOT NULL            | 作成日時               |
| updated_at           | DATETIME     | NOT NULL            | 更新日時               |

### 2.2 contacts（連絡先）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| contact_id           | INTEGER      | PRIMARY KEY AUTOINCREMENT | 連絡先ID（主キー）   |
| user_id              | INTEGER      | FOREIGN KEY REFERENCES users(user_id) | ユーザーID（外部キー） |
| employee_number      | TEXT(16)     | NOT NULL UNIQUE     | 社員番号               |
| last_name            | TEXT(32)     | NOT NULL            | 姓                     |
| first_name           | TEXT(32)     | NOT NULL            | 名                     |
| last_name_kana       | TEXT(64)     |                     | 姓フリガナ             |
| first_name_kana      | TEXT(64)     |                     | 名フリガナ             |
| department           | TEXT(64)     |                     | 部署                   |
| position             | TEXT(64)     |                     | 役職                   |
| birthday             | DATE         |                     | 生年月日               |
| notes                | TEXT(1000)   |                     | 備考                   |
| profile_image        | TEXT(2000)   |                     | プロフィール画像パス    |
| is_favorite          | INTEGER      | NOT NULL DEFAULT 0  | お気に入りフラグ(0:通常, 1:お気に入り) |
| is_deleted           | INTEGER      | NOT NULL DEFAULT 0  | 削除フラグ(0:有効, 1:削除) |
| created_at           | DATETIME     | NOT NULL            | 作成日時               |
| updated_at           | DATETIME     | NOT NULL            | 更新日時               |

### 2.3 contact_phones（電話番号）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| phone_id             | INTEGER      | PRIMARY KEY AUTOINCREMENT | 電話番号ID（主キー） |
| contact_id           | INTEGER      | FOREIGN KEY REFERENCES contacts(contact_id) | 連絡先ID（外部キー） |
| phone_type           | TEXT(16)     |                     | 電話番号種別（社用携帯/個人携帯/自宅） |
| phone_number         | TEXT(20)     | NOT NULL            | 電話番号               |

### 2.4 contact_emails（メールアドレス）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| email_id             | INTEGER      | PRIMARY KEY AUTOINCREMENT | メールID（主キー）   |
| contact_id           | INTEGER      | FOREIGN KEY REFERENCES contacts(contact_id) | 連絡先ID（外部キー） |
| email_type           | TEXT(16)     |                     | メール種別（個人/会社） |
| email_address        | TEXT(128)    | NOT NULL            | メールアドレス         |

### 2.5 contact_addresses（住所）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| address_id           | INTEGER      | PRIMARY KEY AUTOINCREMENT | 住所ID（主キー）     |
| contact_id           | INTEGER      | FOREIGN KEY REFERENCES contacts(contact_id) | 連絡先ID（外部キー） |
| address_type         | TEXT(16)     |                     | 住所種別（自宅/会社）   |
| postal_code          | TEXT(10)     |                     | 郵便番号               |
| prefecture           | TEXT(8)      |                     | 都道府県               |
| city                 | TEXT(64)     |                     | 市区町村               |
| address1             | TEXT(128)    |                     | 住所1                  |
| address2             | TEXT(128)    |                     | 住所2                  |

### 2.6 groups（グループ）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| group_id             | INTEGER      | PRIMARY KEY AUTOINCREMENT | グループID（主キー） |
| user_id              | INTEGER      | FOREIGN KEY REFERENCES users(user_id) | ユーザーID（外部キー） |
| group_name           | TEXT(64)     | NOT NULL            | グループ名             |
| description          | TEXT(256)    |                     | 説明                   |
| created_at           | DATETIME     | NOT NULL            | 作成日時               |

### 2.7 contact_groups（連絡先グループ関係）
| カラム名              | 型           | 制約                | 説明                   |
|----------------------|--------------|---------------------|------------------------|
| contact_id           | INTEGER      | FOREIGN KEY REFERENCES contacts(contact_id) | 連絡先ID（外部キー） |
| group_id             | INTEGER      | FOREIGN KEY REFERENCES groups(group_id) | グループID（外部キー） |
| assigned_at          | DATETIME     | NOT NULL            | 割り当て日時           |

## 3. インデックス・制約
- 社員番号（employee_number）は一意制約（UNIQUE）
- 削除フラグ（is_deleted）は論理削除用
- 外部キー制約はSQLiteのPRAGMA foreign_keys=ONで有効化

## 4. ER図（テキスト簡易表現）
```
users ---< contacts ---< contact_phones
      |            |---< contact_emails
      |            |---< contact_addresses
      |            |---< contact_groups >--- groups
```

## 5. 備考
- 日付・日時はISO8601形式（YYYY-MM-DD, YYYY-MM-DD HH:MM:SS）
- 文字列型はTEXT（SQLite標準）
- 論理削除は is_deleted=1 で判定
- 文字数制限はアプリケーション層でバリデーション実施
- DB制約での文字数チェックはCHECK句でも可能だが、本仕様では説明欄に明記する方式を採用
- 拡張・変更時は本仕様書を更新
